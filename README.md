# apexStore

## Pages

- `index.html` is the welcome page.
- `admin.html` is the sample administrator login and product manager.
- `guest.html` is the guest storefront with product search, category filters, and a printable bill.

## Run locally

Open `index.html` in a modern browser. If the browser blocks JavaScript modules on local files, serve the folder with VS Code Live Server and visit its local URL instead.

The sample administrator credentials are `admin@apexstore.test` / `admin123`. Product data is stored in this browser's local storage. This is a frontend demo only; the sample login is not secure, and the bill does not process orders or payments.
